🛠️ Azure & Entra ID — Bash Automation Lab

Welcome to my personal repository for Azure administration and Entra ID (Azure AD) automation scripts! 🚀

This repository serves as my hands-on learning lab and toolkit for managing Cloud infrastructures, automating identity lifecycles, and reducing administrative friction using Bash and the Azure CLI (az).
🎯 Project Goal

The primary objective is to build modular, production-ready Bash tools to streamline daily Azure operations. Instead of relying solely on repetitive portal clicks or basic, one-off CLI commands, this project focuses on:

    Identity & Access Management (IAM): Automating user creation, group assignments, and offboarding workflows.

    Error Handling & Robustness: Implementing guard clauses, input validation, and structured logging.

    Administrative Efficiency: Eliminating tedious manual steps with clean, interactive, and scriptable solutions.
